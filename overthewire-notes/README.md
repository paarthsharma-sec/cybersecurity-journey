# OverTheWire: Bandit Writeups

## Bandit Level 0

### Objective
Connect to the Bandit server using SSH.

### Commands Used
ssh bandit0@bandit.labs.overthewire.org -p 2220

### What I Learned
- SSH (Secure Shell) is used to remotely connect to servers
- Syntax: ssh username@hostname -p portnumber
- Default SSH port is 22 — this server uses port 2220
- Successfully logged in with username: bandit0 password: bandit0

Easy ✅
